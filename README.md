# BrewHub

BrewHub is a web app built with [Next.js](https://nextjs.org/) that allows you to explore and view details about [Homebrew](https://brew.sh/) formulas. The app lets you:

- Search Homebrew formulas quickly and intuitively
- View details such as versions, dependencies, licenses, and installation statistics
- Analyze dependencies between formulas
- Navigate with a modern, responsive interface optimized for any device

## Main Features

- **Advanced search**: easily find any Homebrew formula
- **Formula details**: complete information for each formula, including changelog and dependencies
- **Statistics**: view installation and popularity stats
- **User experience**: polished UI/UX, dark mode, mobile optimization

## Getting Started

To start the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

You can start editing the main page in `app/page.tsx`. Changes are applied in real time.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to optimize and automatically load the [Geist](https://vercel.com/font) font.
